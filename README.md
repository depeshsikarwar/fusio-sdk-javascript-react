# fusio-sdk-javascript-react

[![CI](https://github.com/depeshsikarwar/fusio-sdk-javascript-react/actions/workflows/ci.yml/badge.svg)](https://github.com/depeshsikarwar/fusio-sdk-javascript-react/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![npm version](https://img.shields.io/npm/v/fusio-sdk.svg?label=fusio-sdk%20peer)](https://www.npmjs.com/package/fusio-sdk)

The React SDK for [Fusio](https://www.fusio-project.org/) — the open source API management platform.

This library provides ready-to-use, framework-agnostic React components for authentication flows (Login, Registration, Password Reset, Account Activation, Change Password) and React hooks for integrating the official [fusio-sdk](https://www.npmjs.com/package/fusio-sdk) or custom generated API SDKs into React applications.

---

## ✨ Features

- 🔑 **Complete Authentication Flow**:
  - `<Login />` — Username/password authentication, password visibility toggle, error handling, and OAuth/Identity providers support.
  - `<Register />` — User registration with email, password confirmation, and captcha support.
  - `<Activate />` — Account activation via token from email.
  - `<PasswordReset />` — Request password reset email.
  - `<PasswordConfirm />` — Execute password reset with verification token.
  - `<ChangePassword />` — Authenticated password update for user profile.
- 🎨 **CSS Framework Agnostic**:
  - Zero CSS framework lock-in. Use standard CSS classes, Tailwind CSS, styled-components, or import our clean default stylesheet powered by CSS variables (`import "fusio-sdk-javascript-react/styles.css"`).
- 🧩 **Type-Safe SDK & Context**:
  - `<FusioProvider />` manages credentials, token persistence (session/local/memory), user profile state, and client lifecycle.
  - Seamless support for custom type-safe frontend SDKs generated by Fusio CLI or backend.
- ♿️ **Accessibility & Security First**:
  - Built following modern web form best practices: semantic HTML `<form>`, correct `autocomplete` attributes, `role="alert"` announcements, and password visibility toggles.
- 📦 **Modern Build & TypeScript**:
  - Full TypeScript declarations (`.d.ts`), Dual ESM and CommonJS exports, and unit test coverage.

## 📦 Installation

Install `fusio-sdk-javascript-react` along with its peer dependency `fusio-sdk`:

```bash
npm install fusio-sdk-javascript-react fusio-sdk
```

Or using Yarn / pnpm:

```bash
yarn add fusio-sdk-javascript-react fusio-sdk
# or
pnpm add fusio-sdk-javascript-react fusio-sdk
```

## 🚀 Quick Start

### 1. Wrap your application with `FusioProvider`

Configure the provider with your Fusio API endpoint:

```tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { FusioProvider } from "fusio-sdk-javascript-react";
import App from "./App";

// Optional: import default stylesheet
import "fusio-sdk-javascript-react/styles.css";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <FusioProvider
      config={{
        baseUrl: "https://api.fusio-project.org", // your Fusio instance URL
        appId: 1,                                  // optional App ID for OAuth identity providers
        appKey: "my-app-key",                      // optional App Key
        autoFetchUser: true,                       // automatically load user profile on mount
      }}
    >
      <App />
    </FusioProvider>
  </React.StrictMode>
);
```

### 2. Add Authentication Components

#### Login Component

```tsx
import React from "react";
import { Login } from "fusio-sdk-javascript-react";

export function LoginPage() {
  return (
    <Login
      onSuccess={(user, jwt) => {
        console.log("Logged in user:", user);
        console.log("Access token:", jwt.token);
      }}
      onError={(err) => {
        console.error("Login failed:", err);
      }}
      onForgotPasswordClick={() => {
        // Navigate to password reset page or modal
      }}
      onRegisterClick={() => {
        // Navigate to registration page or modal
      }}
    />
  );
}
```

#### Registration Component

```tsx
import React from "react";
import { Register } from "fusio-sdk-javascript-react";

export function RegisterPage() {
  return (
    <Register
      onSuccess={(response) => {
        console.log("Registration successful:", response.message);
      }}
      onError={(err) => {
        console.error("Registration failed:", err);
      }}
      onLoginClick={() => {
        // Navigate to login
      }}
    />
  );
}
```

#### Password Reset Flow

**Step 1: Request Password Reset**
```tsx
import React from "react";
import { PasswordReset } from "fusio-sdk-javascript-react";

export function ForgotPasswordPage() {
  return (
    <PasswordReset
      onSuccess={(response) => {
        alert(response.message || "Reset link sent to your email!");
      }}
      onLoginClick={() => {
        // Return to login
      }}
    />
  );
}
```

**Step 2: Confirm Password Reset with Token**
```tsx
import React from "react";
import { PasswordConfirm } from "fusio-sdk-javascript-react";

export function ResetPasswordConfirmPage() {
  // Grab token from URL query params (e.g. ?token=XYZ)
  const params = new URLSearchParams(window.location.search);
  const token = params.get("token") || "";

  return (
    <PasswordConfirm
      token={token}
      onSuccess={(response) => {
        alert("Password reset successfully! You can now log in.");
      }}
      onLoginClick={() => {
        // Navigate to login
      }}
    />
  );
}
```

#### Account Activation

```tsx
import React from "react";
import { Activate } from "fusio-sdk-javascript-react";

export function ActivatePage() {
  const params = new URLSearchParams(window.location.search);
  const token = params.get("token") || "";

  return (
    <Activate
      token={token}
      autoActivate={Boolean(token)} // Auto-triggers activation if token is present
      onSuccess={(response) => {
        console.log("Account activated:", response.message);
      }}
      onLoginClick={() => {
        // Navigate to login
      }}
    />
  );
}
```

#### Change Password (Authenticated Users)

```tsx
import React from "react";
import { ChangePassword } from "fusio-sdk-javascript-react";

export function AccountSecurityPage() {
  return (
    <ChangePassword
      onSuccess={(response) => {
        alert("Password updated successfully!");
      }}
      onError={(err) => {
        console.error("Failed to change password:", err);
      }}
    />
  );
}
```

## 🪝 Hooks Reference

### `useAuth()`

Access the active user session and authentication actions:

```tsx
import { useAuth } from "fusio-sdk-javascript-react";

export function UserProfileHeader() {
  const { user, isAuthenticated, isLoading, logout, refreshUser } = useAuth();

  if (isLoading) return <div>Loading...</div>;

  if (!isAuthenticated || !user) {
    return <a href="/login">Sign In</a>;
  }

  return (
    <div>
      <span>Welcome, {user.name}!</span>
      <button onClick={() => logout()}>Sign Out</button>
    </div>
  );
}
```

### `useFusioClient()`

Access the underlying Fusio SDK clients:

```tsx
import { useEffect, useState } from "react";
import { useFusioClient } from "fusio-sdk-javascript-react";

export function UserAppsList() {
  const { client } = useFusioClient();
  const [apps, setApps] = useState([]);

  useEffect(() => {
    // Calls client.consumer().app().getAll() using authenticated session
    client.consumer().app().getAll().then((res) => {
      setApps(res.entry || []);
    });
  }, [client]);

  return (
    <ul>
      {apps.map((app) => (
        <li key={app.id}>{app.name}</li>
      ))}
    </ul>
  );
}
```

### Integrating Custom Generated SDKs

If you generated a type-safe client for your Fusio endpoints via the Fusio backend or CLI generator:

```tsx
import { useCustomClient } from "fusio-sdk-javascript-react";
import { MyGeneratedClient } from "./generated/MyGeneratedClient";

export function MyComponent() {
  // Instantiates client with your configured baseUrl and current auth Bearer token
  const apiClient = useCustomClient(
    (baseUrl, credentials) => new MyGeneratedClient(baseUrl, credentials)
  );

  const fetchItems = async () => {
    const data = await apiClient.getCustomEndpoint().getAll();
    console.log(data);
  };

  return <button onClick={fetchItems}>Load Data</button>;
}
```

## 🎨 Styling & Customization

### Default Styles (CSS Variables)

Import the default CSS file:

```tsx
import "fusio-sdk-javascript-react/styles.css";
```

Customize theme colors and appearance by overriding CSS variables:

```css
:root {
  --fusio-primary: #6366f1;         /* Primary brand color */
  --fusio-primary-hover: #4f46e5;
  --fusio-radius: 12px;             /* Corner radius */
  --fusio-font-family: 'Inter', sans-serif;
}
```

### Custom Class Names & Tailoring

Each component supports `className` and `style` props, and semantic internal classes:
- `.fusio-component`
- `.fusio-form`
- `.fusio-form-group`
- `.fusio-label`
- `.fusio-input`
- `.fusio-button`
- `.fusio-message`
- `.fusio-oauth-button`

You can also override labels, placeholders, and error messages via the `labels` prop on every component.
